# Contributing

Thanks for improving File Converter Hub.

1. Fork the repository and create a focused branch.
2. Keep conversion behavior deterministic and local-first.
3. Add or update tests for every behavior change.
4. Run `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test`.
5. Update both English and Arabic README sections when user-facing behavior changes.
6. Never commit private files, credentials, generated build output, or test fixtures containing real personal data.

Please keep pull requests small enough to review and explain compatibility or data-loss implications for new converters.
